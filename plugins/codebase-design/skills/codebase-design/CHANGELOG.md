# Changelog

All notable changes to the `codebase-design` skill will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-01

### Added
- Initial release of `codebase-design` skill.
- Diagnostic framework for Deep Modules vs. Shallow Modules (John Ousterhout).
- Seams, Leverage, and Locality architectural metrics.
- Refactoring recipes for collapsing pass-through sprawl and pushing invariants down into rich entities.
