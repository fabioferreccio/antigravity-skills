# i18n Review Lens

i18n review lens.

## Checks
1. **Hardcoded user-facing strings** in NEW code
2. **Key reuse** (search for semantically identical existing keys)
3. **Missing translations** (key added to one language but missing from others)
4. **Convention compliance** (project-specific key structure)
5. **Unused keys** (removed from code but still in translation files)
6. **Date/number formatting** (hardcoded formats vs locale-aware)
7. **Plural rules handling**
8. **RTL support** (if applicable)
