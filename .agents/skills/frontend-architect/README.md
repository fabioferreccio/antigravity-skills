# Frontend Architect Skill

`frontend-architect` is a supreme cognitive skill for Antigravity agents, specializing in Front-End Architecture, Component Engineering, User Experience, Accessibility (WCAG 2.2), Monorepos, State Management, and TDD testing.

## Overview

This skill integrates end-to-end front-end engineering practices into a single reference-based modular system. It replaces fragmented workflows by combining structural component design with strict accessibility, performance budgets, and modern tooling standards.

## Capabilities

- **Component Patterns**: Atomic Design, Compound Components, Headless UI primitives, Polymorphic components, and Custom Hook composition.
- **UX & Accessibility**: Complete audit framework for WCAG 2.2 AA/AAA compliance, Nielsen 10 Usability Heuristics, ARIA roles, focus management, and microcopy.
- **State Management**: Multi-tier state separation (Local UI, Global App State, Server State via TanStack Query / SWR, Form State via React Hook Form + Zod, URL State).
- **Performance & Reactivity**: Virtual DOM mechanics, fine-grained reactivity, Core Web Vitals optimization (LCP, CLS, INP), code-splitting, and SSR/SSG/ISR rendering modes.
- **Monorepos & Tooling**: Turborepo workspace topology, pnpm workspaces, Vite + React builds, TypeScript strict mode, ESLint flat configs, Prettier, CI/CD, and MDX.
- **Testing & TDD**: Test-Driven Development (Red-Green-Refactor) with Vitest and React Testing Library using strict Triple AAA (Arrange, Act, Assert) structure.
- **Design Systems**: Design Tokens architecture, TailwindCSS, Class Variance Authority (CVA), and Radix UI / Headless UI primitives.
- **Micro-Frontends**: Module Federation, Web Components, Island Architecture, and shared package isolation.
