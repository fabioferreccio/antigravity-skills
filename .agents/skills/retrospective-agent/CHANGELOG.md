## [1.0.0] - 2026-10-01

### Added
- Initial release of `retrospective-agent`.
- Reference guide on compound learning and institutional memory (`references/compound-learning.md`).
- Reference guide on rule pruning and context token hygiene (`references/rule-pruning.md`).
- 5-phase retrospective pipeline (Friction Audit, Root Cause Abstraction, Context Hygiene Audit, Change Proposal, Interactive Approval).
- Comprehensive evaluation test suite and usage example.
