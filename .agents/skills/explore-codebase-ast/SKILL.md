# Goal

Map a project's architecture (classes, methods, interfaces, controllers, inheritance) using Abstract Syntax Tree (AST) parsing to prevent context window overflow. This allows the AI to understand the structure of the codebase efficiently before reading specific large files.

# Instructions

1. **Validate Environment**: 
   - Check if Python is installed (`python --version` or `python3 --version`). 
   - Check if Node.js is installed (`node --version`).
   - If Python is available, prefer it, as the Python script utilizes the `tree-sitter-languages` package which comes with pre-compiled polyglot support.
   - If only Node.js is available, use the fallback Node script.
   
2. **Setup Dependencies**:
   - For Python: Run `pip install tree-sitter tree-sitter-languages` (or ensure it's in a virtual environment).
   - For Node: Run `npm install tree-sitter` and the specific language parser (e.g., `tree-sitter-javascript`, `tree-sitter-typescript`, etc.) in the `.agents/skills/explore-codebase-ast/scripts` directory.

3. **Execute Parser**:
   - Run the appropriate script passing the directory path, depth, and target extensions.
   - Python: `python .agents/skills/explore-codebase-ast/scripts/explore.py <directory> <extensions> <depth>`
   - Node: `node .agents/skills/explore-codebase-ast/scripts/explore.js <directory> <extensions> <depth>`
   - Example extensions: `.ts,.js` or `.py` or `.cs,.java`.

4. **Analyze Output**:
   - Read the Markdown output generated by the script.
   - Present a concise, high-level architectural summary to the user based on the generated map.

# Conventions

- **Token Efficiency**: The generated output is optimized for LLM reading (Markdown format with semantic headers and lists).
- **Graceful Fallback**: If a specific file fails to parse, the script will skip it or provide partial information without crashing.

# Constraints

- Do NOT load giant files into memory; rely on the script's AST parsing.
- Do NOT execute destructive commands.
- ALWAYS respect the depth limit to avoid traversing infinite directories (like `node_modules` or `.git`). The script automatically ignores common vendored directories.

# Output Format

The output is a Markdown representation of the directory tree with internal AST structures:

```markdown
📁 src
  📁 controllers
    📄 UserController.ts
      - Class: UserController (extends BaseController)
        - Method: getUser(id)
        - Method: createUser(data)
```
